01

Admin membuat kode pairing sementara. Kode hanya dapat digunakan sekali untuk menghubungkan browser ini.

02

Setujui lokasi

Browser meminta izin saat Anda memulai. Berbagi hanya berjalan saat halaman ini terbuka dan tidak dihentikan.

03

Admin melihat lokasi

Dashboard admin menampilkan lokasi terbaru dan akurasinya. Riwayat perjalanan tidak disimpan.

Tentang izin dan akurasi. Browser meminta izin lokasi melalui sistem perangkat dan dapat menggunakan sumber lokasi yang tersedia, tetapi tidak memberi tahu apakah koordinat berasal dari GPS atau jaringan. Browser web tidak dapat membaca atau meminta lokasi BTS secara langsung. HTTPS diperlukan untuk akses lokasi; pembaruan dapat tertunda saat tab tidak aktif, browser dibatasi, atau koneksi terputus.
